# Fit2Move Dataset

## ItemFits Open Catalog Database

This repository contains a fixed snapshot of the ItemFits Open Catalog Database used for the Fit2Move project.

- Original source: ItemFits Open Catalog Database
- Source URL: https://itemfits.com/data/catalog
- Snapshot generated: November 4, 2026
- File: itemfits-catalog-2026-11-04.csv
- Records in the snapshot: 654
- Use in Fit2Move: Vehicle cargo-space and loading-opening dimensions
- Dataset reuse: Free to reuse with attribution to ItemFits, as stated by the original source.

The dataset remains the property of its original source. This repository stores a fixed snapshot for academic analysis and reproducibility.
